# ScheduledExecutorService — планировщик задач

Краткая теоретическая сводка. Код — в `src/main/java/com/savadanko/javarepo/scheduler/`.

## Что это и зачем

**ScheduledExecutorService** — стандартный планировщик из `java.util.concurrent`:
выполняет задачи **с задержкой** или **периодически** на пуле потоков. Нужен,
когда требуется отложить работу или повторять её по расписанию (опрос, очистка,
heartbeat), не блокируя основной поток и не плодя `Thread` вручную. Современная
замена устаревшего `Timer`/`TimerTask`: устойчив к исключениям в задачах и
использует пул потоков.

## Ключевые понятия

- **Пул потоков** — создаётся через `Executors.newScheduledThreadPool(n)`.
  Размер `n` определяет, сколько задач могут идти параллельно.

- **`schedule(task, delay, unit)`** — выполнить задачу **один раз** через
  заданную задержку.

- **`scheduleAtFixedRate(task, initialDelay, period, unit)`** — периодически,
  отсчёт периода от **старта** предыдущего запуска. Если задача дольше периода,
  следующие запуски идут подряд без наложения (период «нагоняется»).

- **`scheduleWithFixedDelay(task, initialDelay, delay, unit)`** — периодически,
  пауза отсчитывается от **окончания** предыдущего запуска. Гарантирует
  фиксированный промежуток между выполнениями.

- **`ScheduledFuture`** — дескриптор запланированной задачи: позволяет отменить
  её (`cancel`) или дождаться/получить результат.

- **Завершение (`shutdown` / `shutdownNow`)** — `shutdown()` перестаёт принимать
  новые задачи и доисполняет текущие; `shutdownNow()` пытается прервать всё
  немедленно. Без завершения потоки пула не дадут JVM остановиться.

## Полезно знать

- **fixedRate vs fixedDelay** — главное различие темы: fixedRate держит частоту,
  fixedDelay держит паузу между запусками. Для долгих задач почти всегда нужен
  fixedDelay.
- **Исключение в периодической задаче** молча отменяет дальнейшие её запуски —
  оборачивай тело в try/catch, если повтор важен.
- Для отсчёта пауз в тестах удобен `CountDownLatch` вместо «спящих» проверок.

## Запуск

```bash
./gradlew run     # SchedulerDemo: тики каждые 0.5с + одноразовая задача
./gradlew test    # проверки runOnce / fixedRate / остановки после close()
```
