# Cron и Spring CronExpression

Краткая теоретическая сводка. Код — в `src/main/java/com/savadanko/javarepo/cron/`.

## Что это и зачем

**Cron** — компактный синтаксис для описания повторяющегося расписания
(«каждый час», «в 9:00 по будням»). Пришёл из Unix; используется во всех
Java-планировщиках (`@Scheduled(cron=...)`, Quartz `CronTrigger`). Сам по себе
cron ничего не запускает — это лишь правило, по которому **вычисляются моменты
срабатывания**. Здесь смотрим именно на разбор выражения и вычисление времён —
без планировщика, через `org.springframework.scheduling.support.CronExpression`.

## Синтаксис (формат Spring — 6 полей)

```
 ┌── секунды (0-59)
 │ ┌── минуты (0-59)
 │ │ ┌── часы (0-23)
 │ │ │ ┌── день месяца (1-31)
 │ │ │ │ ┌── месяц (1-12 или JAN-DEC)
 │ │ │ │ │ ┌── день недели (0-7 или MON-SUN; 0 и 7 = воскресенье)
 │ │ │ │ │ │
 * * * * * *
```

> Внимание: Unix-cron и Quartz-cron имеют **5 и 7** полей соответственно.
> У Spring их **6** (добавлено поле секунд, нет поля года).

## Ключевые понятия

- **Спецсимволы полей:**
  - `*` — любое значение.
  - `,` — список (`MON,WED,FRI`).
  - `-` — диапазон (`9-17`).
  - `/` — шаг (`*/15` — каждые 15).
  - `?` — «не важно» для дня (день месяца / день недели).
  - `L`, `#` — последний / N-й день (например `FRI#2` — вторая пятница).

- **`CronExpression.parse(str)`** — разбирает выражение; кидает
  `IllegalArgumentException` при ошибке.

- **`expression.next(from)`** — возвращает ближайший момент срабатывания строго
  **после** `from` (тип `Temporal`, напр. `LocalDateTime`), либо `null`, если
  срабатываний больше не будет.

- **`CronExpression.isValidExpression(str)`** — проверка корректности без
  исключения.

- **Макросы Spring** — готовые имена: `@hourly`, `@daily`, `@weekly`,
  `@monthly`, `@yearly`.

## Полезно знать

- `next()` всегда строго **после** переданного момента — повторный вызов с его
  же результатом даёт следующий, что удобно для генерации серии запусков.
- Cron описывает «когда», но не «выполняет» — чтобы реально запускать задачи,
  нужен планировщик (см. темы `spring-scheduled`, `quartz`) или ручная связка с
  `ScheduledExecutorService` (тема `scheduler`).
- Диалекты cron различаются — выражение из Unix/Quartz не всегда валидно в Spring.

## Запуск

```bash
./gradlew run    # печатает ближайшие срабатывания для набора cron-выражений
./gradlew test   # детерминированные проверки next()/диапазонов/валидации
```
