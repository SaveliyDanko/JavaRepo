# Quartz Scheduler

Краткая теоретическая сводка. Код — в `src/main/java/com/savadanko/javarepo/quartz/`.

## Что это и зачем

**Quartz** — полноценная библиотека планирования задач для Java, мощнее, чем
`@Scheduled` и `ScheduledExecutorService`. Нужна, когда требуется: **персистентность**
расписаний (пережить рестарт через БД), **кластеризация** (несколько узлов делят
задачи, не дублируя их), гибкие **триггеры** (cron, календари, misfire-политики) и
управление джобами в рантайме. Если хватает простого периодического метода —
бери `@Scheduled`; Quartz берут под «тяжёлые» сценарии.

## Ключевые понятия

- **Job** — единица работы: класс с методом `execute(JobExecutionContext)`.
  Содержит логику, которую надо выполнить.

- **JobDetail** — описание экземпляра джоба: его класс, уникальное имя (`JobKey`)
  и параметры. Один класс джоба можно использовать в нескольких JobDetail.

- **Trigger** — расписание: когда и как часто запускать джоб. Основные виды:
  - **SimpleTrigger** — повтор с фиксированным интервалом N раз / бесконечно.
  - **CronTrigger** — запуск по cron-выражению.

- **Scheduler** — ядро Quartz: связывает JobDetail с Trigger и исполняет их.
  Spring Boot создаёт и стартует его автоматически.

- **JobDataMap** — словарь параметров, передаваемых в джоб (через JobDetail или
  Trigger). Читается из `JobExecutionContext` внутри `execute`.

- **JobStore** — где хранятся джобы и триггеры:
  - **RAMJobStore** (`job-store-type: memory`) — в памяти, быстро, теряется при
    рестарте (используется здесь).
  - **JDBCJobStore** — в БД, переживает рестарт и нужен для кластера.

## Полезно знать

- **`storeDurably()`** у JobDetail позволяет джобу существовать без привязанного
  триггера (иначе Quartz требует хотя бы один триггер при регистрации).
- **DI в джобах**: spring-boot-starter-quartz ставит `SpringBeanJobFactory`,
  поэтому в Job-класс можно внедрять Spring-бины.
- **Misfire** — что делать, если запуск пропущен (например, приложение лежало):
  у триггеров настраиваются misfire-политики.
- Сравнение тем: `scheduler` (ручной пул) → `spring-scheduled` (декларативно) →
  **`quartz`** (персистентность, кластер, богатые триггеры).

## Запуск

```bash
./gradlew bootRun   # Scheduler стартует, ReportJob срабатывает каждые 0.5с
./gradlew test      # проверка, что джоб запускается по триггеру
```
