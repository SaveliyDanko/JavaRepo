# JMS — Java Message Service

Краткая теоретическая сводка по теме. Код — в `src/main/java/com/savadanko/javarepo/jms/`.

## Что это и зачем

**JMS** — стандартный Java-API для обмена сообщениями между приложениями через
брокер (промежуточное звено). Нужен для **асинхронной** и **слабосвязанной**
коммуникации: отправитель кладёт сообщение и не ждёт получателя, компоненты не
знают друг о друге напрямую. Это даёт устойчивость к нагрузке и сбоям (сообщения
буферизуются в брокере).

## Ключевые понятия

- **Broker (брокер)** — сервер, принимающий, хранящий и доставляющий сообщения
  (здесь — ActiveMQ Artemis в embedded-режиме, внутри процесса).

- **Destination (назначение)** — куда отправляется сообщение. Два вида:
  - **Queue (очередь)** — модель *point-to-point*: сообщение получает ровно один
    потребитель. Подходит для задач/команд.
  - **Topic (тема)** — модель *publish/subscribe*: сообщение получают все активные
    подписчики. Подходит для событий/уведомлений.

- **Producer (производитель)** — отправляет сообщения в destination.

- **Consumer (потребитель)** — читает сообщения из destination.

- **Message (сообщение)** — единица данных: заголовки + свойства + тело
  (текст, объект, байты и т.д.).

## Spring-абстракции (что используем в коде)

- **JmsTemplate** — упрощает отправку и синхронный приём: сам управляет
  подключением, сессией и продюсером. `convertAndSend(...)` сериализует объект в
  сообщение.

- **@JmsListener** — помечает метод как асинхронный слушатель очереди/темы;
  Spring сам вызывает его для каждого пришедшего сообщения.

- **@EnableJms** — включает обработку аннотаций `@JmsListener` в приложении.

- **MessageConverter** — преобразует Java-объекты в JMS-сообщения и обратно
  (по умолчанию строки и простые типы; для POJO часто берут JSON-конвертер).

## Полезно знать

- Доставка **асинхронная** — в тестах ждём приёма (здесь через Awaitility).
- **Acknowledge / транзакции** — подтверждение получения; при ошибке сообщение
  можно вернуть в очередь или отправить в **DLQ** (dead-letter queue).
- Для внешнего брокера: `spring.artemis.mode: native` + `broker-url`.
