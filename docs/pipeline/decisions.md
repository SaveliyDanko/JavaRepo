- 2026-06-18 · DETAIL(02) · `Category{NEGATIVE,ZERO,ONE,PRIME,COMPOSITE}` + метод `isStandard()` · даёт естественный объект для `@EnumSource` и демонстрацию фильтра `names`/`mode`.
