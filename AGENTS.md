# AGENTS.md

Правила работы с этим репозиторием для AI-ассистентов (Claude Code и др.).

## Назначение

Учебный репозиторий для изучения и практики Java. Цель — не только рабочий
код, но и закрепление понимания изучаемых тем.

## Ветка `main`

`main` держится **максимально чистым**: только Java 21 + Gradle (Kotlin DSL) + JUnit 5.
Никакие тематические зависимости (Spring, JMS, JPA, БД и т.п.) в `main` не добавляются.

## Рабочий процесс для каждой новой темы

1. **Отдельная ветка.** Каждая новая тема изучения разрабатывается в своей
   ветке, ответвлённой от `main` (например `jms`, `jpa`, `concurrency`).
   Тематические зависимости подключаются только в этой ветке.

2. **Краткие комментарии в коде.** Учебный код снабжается короткими
   поясняющими комментариями — что и зачем делается.

3. **Теоретическая сводка в `docs/`.** Для каждой темы создаётся
   `docs/<тема>.md` с краткой теорией: что это, для чего нужно, ключевые
   понятия — буквально несколько предложений на понятие. Целостно тему
   раскрывать не нужно, если она того не требует.

Подробный гайд с шагами, форматом сводки и чек-листом —
[docs/how-to-add-a-topic.md](docs/how-to-add-a-topic.md).

## Стек

- **Java 21** (LTS)
- **Gradle** (Kotlin DSL, `build.gradle.kts`) + wrapper
- **JUnit 5** — тесты
- Тематические фреймворки добавляются по ветке.
